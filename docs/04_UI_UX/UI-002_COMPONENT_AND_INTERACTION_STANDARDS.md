# UI-002 — Component & Interaction Standards

| Field | Value |
|---|---|
| Version | 1.0.0 |
| Status | Draft |
| Depends on | MD-400, UI-001 |

## Required reusable components

Application shell, scope switcher, freshness badge, KPI card, attention item, data table, saved filter, detail drawer, evidence link, document preview, command/search palette, date/currency input, approval panel, empty/loading/error state, and confirmation dialog.

## Interaction rules

- Forms validate before submit and after server response; explain a corrective action.
- "Save" states disclose whether a record is draft, submitted, approved, or posted.
- A relationship or monetary figure opens an authorized detail view with evidence and history.
- Critical actions never rely on hover, color, or transient notification alone.
- Mobile prioritizes review, search, capture, task completion, and approval; dense accounting entry remains a desktop-first workspace.
