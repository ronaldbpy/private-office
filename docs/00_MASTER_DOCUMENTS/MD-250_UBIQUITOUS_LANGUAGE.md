# MD-250 — Ubiquitous Language

| Field | Value |
|---|---|
| Version | 1.0.0 |
| Status | Draft |
| Depends on | MD-000, MD-200 |

This vocabulary is mandatory for product copy, APIs, schemas, documentation, and code. Do not replace terms with informal synonyms.

| Term | Official definition |
|---|---|
| Group | The complete administrative boundary managed by Private Office. |
| Economic owner | A person or entity that controls or economically benefits from group value, directly or indirectly. |
| Legal entity | A legally recognized company or person used in a legal, tax, or accounting capacity. |
| Holding | A legal entity primarily intended to hold ownership interests or investments. |
| Ownership interest | A dated ownership, economic-rights, or control relationship from one party to another. |
| Project | A bounded economic initiative that can span entities and people. |
| Estate | The aggregate assets, rights, and obligations considered from an owner or group perspective. |
| Asset | A resource with measurable economic value and an accountable owner. |
| Liability | A present economic obligation with a debtor, creditor, and status. |
| Financial account | A location or provider account holding cash or financial instruments: bank, cashbox, wallet, broker, exchange, or fund. |
| Movement | An observed or recorded change in value, balance, or position. It is never silently deleted. |
| Transaction | The business-level grouping of related movements, documents, commitments, and accounting effects. |
| Event | An immutable fact recorded on the timeline; it may be financial or non-financial. |
| Document | A digital artifact with provenance, version history, permissions, and explicit relationships. |
| Vault | The controlled document repository and knowledge layer; it is not a generic file folder. |
| Accounting entry | The formal double-entry accounting representation of a transaction. |
| Insight | An evidence-linked conclusion generated by analysis or AI; it is not a source fact. |
| Alert | A time-sensitive condition requiring visibility or action. |

## Language rules

- "Movement" is not "transaction"; a transaction can contain many movements.
- "Event" records that something happened; it does not replace the authoritative entity record.
- "Delete" means logical deletion only where permitted. Financial and audit records use reversal or archival.
- "Consolidated" must always name its scope and calculation method.
