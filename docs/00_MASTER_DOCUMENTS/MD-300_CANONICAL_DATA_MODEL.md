# MD-300 — Canonical Data Model

| Field | Value |
|---|---|
| Version | 1.0.0 |
| Status | Draft |
| Depends on | MD-200, MD-250 |

## Purpose

Define the technology-independent business model. Database tables, ERP records, search indexes, and API payloads are projections of this model, not substitutes for it.

## Universal record envelope

Every canonical record must have a stable UUID, lifecycle status, creation and update timestamps, actor attribution, tenant/group scope, audit lineage, and discoverable relationships. Where applicable it also has source system identity, effective dates, attachments, tags, and classifications.

## Canonical aggregates

| Aggregate | Responsibility |
|---|---|
| Party | Person, legal entity, customer, supplier, employee, and related identities. |
| Organization graph | Group membership, ownership interests, control, governance and intercompany relationships. |
| Project | Economic initiative, participants, budget, commitments, outcomes and timeline. |
| Treasury | Financial accounts, imported statements, movements, reconciliation and liquidity forecasts. |
| Transaction | Business transaction, line items, evidence, approvals, movements and accounting links. |
| Estate | Assets, liabilities, valuation, ownership, condition, insurance and lifecycle. |
| Vault | Documents, versions, extracted facts, permissions and relationships. |
| Accounting projection | Chart of accounts, journal entries, periods, tax and financial statements. |
| Work and intelligence | Tasks, calendar items, alerts, insights, decisions and notifications. |

## Invariants

- UUIDs are generated by Private Office and never reused, even if an external system changes.
- Monetary amounts require an ISO 4217 currency and must retain original amount and valuation basis when converted.
- Relationships are first-class, typed, directionally explicit, and, when relevant, effective-dated.
- Source documents and imported bank data remain immutable originals. Enrichment is stored separately.
- Records that affect accounting or reported balances require a source, authorization state, and reversal/correction linkage.
