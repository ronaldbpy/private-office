# MD-900 — Master Roadmap

| Field | Value |
|---|---|
| Version | 1.0.0 |
| Status | Draft |
| Depends on | MD-000 through MD-800 |

## Delivery rule

The order protects integrity: do not implement a later capability where it depends on foundational identity, authorization, data lineage, or accounting controls that do not yet exist.

| Phase | Outcome | Primary scope |
|---|---|---|
| 0 — Foundation | Governed delivery base | documentation, repository, ADRs, environments, identity, observability |
| 1 — Private Office Core | Secure group workspace | group/parties, roles, dashboard, timeline, Vault basics, calendar, search |
| 2 — Financial Core | Reliable liquidity operations | accounts, imports, movements, reconciliation, receivables/payables, forecasts |
| 3 — Accounting Core | Accountant-ready formal reporting | accounting engine integration, journals, tax workflow, intercompany and consolidation views |
| 4 — Projects & Contracts | Investment and operating visibility | projects, commitments, contracts, budget/actuals |
| 5 — Estate Management | Complete estate picture | assets, liabilities, valuation, insurance, ownership and crypto positions |
| 6 — Intelligence | Evidence-bound decision support | POI, document intelligence, insights, scenarios |
| 7 — Automation | Controlled recurring work | reminders, approvals, notifications and workflows |
| 8 — Executive | Decision-grade consolidated reporting | KPIs, board reports, estate and cash-flow views |
| 9 — Mobile | Mature PWA experience | mobile workflows, offline boundaries, push notifications |
| 10 — Ecosystem | Validated external capabilities | banking, e-invoicing, signature, API partners |

## Entry criteria for production financial use

No phase handling production finance is complete without documented authorization, auditability, backups, restoration proof, data import/reconciliation controls, monitoring, accountant validation where relevant, and acceptance evidence.
